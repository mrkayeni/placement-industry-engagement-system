# Placement and Industry Engagement Management System

## Overview
A multi-user Placement and Industry Engagement Management System developed in Python using object-oriented programming principles, Tkinter GUI, and SQLite database integration.

The system was designed to support:
- Students
- Placement Teams
- Academic Supervisors
- Industry Partners

## Features
- User authentication
- Role-based dashboards
- Placement opportunity management
- Student application tracking
- Document upload support
- Progress monitoring
- Reports and analytics
- Notifications and alerts

## Technologies Used
- Python
- Tkinter
- SQLite
- Object-Oriented Programming

## How to Run
1. Open `placement_system_app.py` in Spyder or any Python IDE
